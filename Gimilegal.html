⚙️ Technical Disclosures, API & PWA Architecture

1. Quranic Data Source & Public API Attribution

AdeenDesk utilizes the open-source, community-verified Alquran.cloud API (Islamic Network) to fetch authentic Uthmani Arabic script, recitation metadata, and multi-language translations (Urdu, English, and Hindi). We do not claim ownership of the divine text; all Quranic data is served purely for non-commercial educational reading. We express gratitude to the open-source Islamic developers maintaining these accurate endpoints.

2. Offline PWA, Network-First Caching & Update Transparency

AdeenDesk is engineered as an installable Progressive Web App (PWA). To ensure users receive the latest daily content, prayer time adjustments, and news updates without stale data issues, our Service Worker implements a Network-First caching strategy.

  • Network-First Logic: The application prioritizes fetching the freshest server-side content on connected sessions, falling back gracefully to local browser cache when offline.
  • Manual Update / Refresh Mechanism: In the event of a background Service Worker release, a prominent update prompt / refresh button is triggered, enabling users to purge legacy cache and reload the latest build instantaneously with zero data loss.
